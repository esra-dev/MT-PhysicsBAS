## Bootstrap and interpretation limits

Exactly 10,000 paired-seed replicates used one `random.Random(20260727)` instance. Each replicate used 20 successive `randrange(20)` draws shared across every cell and outcome. Percentiles use sorted linear interpolation: h=(n-1)*p, i=floor(h), x_i+(h-i)*(x_(i+1)-x_i).

Undefined bootstrap rank replicates are excluded only from their finite percentile vector and their count remains in `ordering_assessment.csv`.

Resampling seeds does not create independent lab designs. Cells sharing a physical design or parent topology are not independent mechanism replications.

Combined serialized Q-values are primary. Summed logical-zone values are retained only as a serialization diagnostic.
