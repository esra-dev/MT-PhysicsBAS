## Motivation — two gaps closed by one cell

1. **The multi-fault family covers lamps only.** The "several components broken
   at once" cells (`lab2_f2dead/f2inv`, `lab3_f2dead/f2inv`) inject Causes
   lamps exclusively; the Mediates (blind) fault class introduced in Phase 2.4
   has only single-fault cells (`*_f1bdead`, `*_f1binv`). No cell exercises the
   **iterative** detect→blacklist→warm-restart loop on IV-gated actuators.
2. **No lamp multi-fault cell is well-posed.** `lab2_f2dead/f2inv` and
   `lab3_f2dead/f2inv` leave only sun-gated survivors (ill-posed for a
   recovery-speed contrast); the `*_lowsun` cells are degraded best-effort
   cells (nominal goal provably unreachable). There is no multi-fault cell
   where full rank-3 recovery is deterministically possible.

`lab3_f2bdead` closes both: **both blinds die**, so the agent must run the
active OPEN-probe self-test twice and blacklist iteratively, and the survivors
(Z1Light, Z2Light, Spotlight) keep both zones deterministically rank-3
reachable — per-zone ceiling 25 + 400 (own lamp) + 100 (cross lamp) + 150
(spotlight) = 675 lux.

It is also a direct probe of the **§9.10 binding-constraint reading** ("the KG
advantage concentrates where recovery requires re-ranking multiple surviving
actuators"): three survivors must be re-ranked after two blacklists, so the
reading predicts Δ < 0 (KG faster). A null would instead say the warm-started
lamp policy already dominates in both arms — blinds are redundant under a
goal-only reward, so losing them may force no re-ranking at all. Both outcomes
are informative; the directional expectation is stated pre-dispatch in §9.11.

## Detection path

A dead blind is invisible to passive monitoring (never on the greedy path;
only falsifiable OPEN under sun rank ≥ 2 with headroom). The Phase 2.4 active
self-test handles each blind independently: on the first episode whose pinned
sunshine draw is rank ≥ 2, the agent probes an unverified blind's OPEN action;
a healthy blind would be verified once (`probeVerified`), a dead one is
instantly blacklisted. With two dead blinds the loop fires twice —
DetectEpisode ≈ 6–8 per blind expected (probe-bound, as in the f1b* cells).
No Java/ASL change was needed: the probe scaffolding already iterates over all
unverified IV-gated actuators.

Against the three pre-stated observables:

1. **Iterative Mediates detection: confirmed.** Both blinds blacklisted in all
   20 replicas (recall 1.0 both arms); first blacklist at ep 2–8, second at
   ep 3–87 (probe-bound). The KG arm probed descriptively earlier (Δ = −2.0).
2. **Recovery contrast: the Δ < 0 expectation was NOT met.** The realized
   outcome is the redundancy reading, with an adverse (ns) trend: survivors
   are exactly the levers the warm-started policy already ranks correctly, so
   both arms pay the generic lab3 re-learning cost and the KG arm's retained
   priors trend toward overhead — the same pattern as `lab3_f1dead` (+85.0)
   and `labmon_f1dead` (+22.2). The forward test narrows the §9.10
   binding-constraint reading: multi-survivor re-ranking is necessary but not
   sufficient; the advantage requires that the fault promote survivors the
   warm-started policy had learned to ignore.
3. **Goal-reaching certification: confirmed.** RecoveredGoalRate 0.755 / 0.940
   (both ≥ 0.5, reconvergence 1.0 both arms) — the cell classifies
   confirmatory while remaining outside the frozen family (q = nan).
